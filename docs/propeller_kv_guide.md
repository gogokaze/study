# 프로펠러 크기와 KV의 원리

## KV란?

```
KV = RPM / Volt
```

| KV | 1V당 RPM |
|----|---------|
| 1000KV | 1000 RPM |
| 3000KV | 3000 RPM |
| 6000KV | 6000 RPM |

---

## 핵심 원리

```
큰 프로펠러 → 더 많은 공기를 밀어야 함 → 더 큰 토크 필요 → 낮은 KV
작은 프로펠러 → 공기 저항이 적음 → 고속 회전 가능 → 높은 KV
```

### 자동차 기어 비유

| 기어 | 특성 | 드론 대응 |
|------|------|----------|
| 저단 | 힘 큼, 속도 낮음 | 낮은 KV + 큰 프롭 |
| 고단 | 힘 작음, 속도 높음 | 높은 KV + 작은 프롭 |

---

## 프롭 크기별 KV 가이드

### 2.5인치

- **KV 범위:** 5000~12000KV
- **특성:** 작은 부하 → 고속 회전
- **용도:** TinyWhoop, 레이싱 드론

### 3인치

- **KV 범위:** 3500~7000KV
- **특성:** 균형형
- **용도:** Toothpick, Micro FPV

### 3.5인치

- **KV 범위:** 2500~4500KV
- **특성:** 공기 저항 증가 → 토크 요구 증가
- **용도:** GPS 드론, ArduPilot, Long Range

### 4인치

- **KV 범위:** 1800~3500KV
- **특성:** 큰 디스크 면적 → 높은 효율
- **용도:** 장거리 비행, 측량, 자율비행

---

## 추력 관계

```
추력 ∝ 프로펠러 직경⁴
```

3인치 → 4인치만 되어도 필요한 토크가 크게 증가 → KV를 낮춰야 함
