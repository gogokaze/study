# 네이버 광고주센터 · 검색광고 대시보드

네이버 검색광고(파워링크) **통합 키워드** 캠페인의 광고그룹 관리 화면을
재현한 정적 대시보드입니다. 외부 의존성 없이 브라우저에서 바로 열립니다.

## 실행

```bash
# 그냥 파일을 열거나
open index.html          # macOS
# 로컬 서버로
python3 -m http.server 8080   # → http://localhost:8080
```

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 대시보드 UI 전체 (GNB · 사이드바 · 캠페인 카드 · 광고그룹 표 · 푸터) |
| `data.js` | 캠페인 정보와 광고그룹 50개의 지표 데이터 (`window.CAMPAIGN`) |

## 기능

- **광고그룹 표** — 노출수 / 클릭수 / 클릭률 / 평균 CPC / 총비용 (50개 그룹)
- **정렬** — 열 헤더 클릭 시 오름/내림차순 토글
- **필터** — 광고그룹 이름으로 실시간 검색
- **ON/OFF 토글** — 그룹별 운영 상태 전환 (요약 합계에 반영)
- **요약 행** — 표시 중인 ON 상태 그룹 기준으로 노출·클릭·CTR·CPC·비용 재집계

## 데이터

`data.js`의 `window.CAMPAIGN.groups` 배열을 수정하면 표가 그대로 갱신됩니다.
현재 데이터의 합계는 캠페인 원본 요약값과 일치합니다.

- 노출수 합계: 5,636
- 클릭수 합계: 27
- 총비용 합계: 31,703원
- 통합 CTR: 0.48% · 통합 CPC: 1,174원
