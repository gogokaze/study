# 메인보드 수리 원리

## 1. 1V 주입 원칙 (Short Circuit Localization)

### 목적

전원 레일에 단락(short)이 있을 때, **어느 부품이 단락됐는지** 열로 시각화하는 비파괴 진단법.

### 원리

```
외부 전원공급기 (1V / 전류제한 0.5~1A)
         │
         ▼
   VCC 테스트 포인트 (단락된 레일)
         │
    ┌────┴──────────────────────────────┐
    │ 정상 부품 (저항 높음)              │
    │   I = V/R → 소전류 → 발열 없음   │
    └───────────────────────────────────┘
    │ 단락 부품 (저항 ≈ 0Ω)             │
    │   I = V/R → 대전류 → P=I²R 발열  │ ← 열화상 카메라로 탐지
    └───────────────────────────────────┘
```

### 왜 1V인가?

| 이유 | 설명 |
|------|------|
| 반도체 보호 | 실리콘 다이오드 순방향 전압(~0.7V) 이하 → 정상 부품 손상 없음 |
| 단락 가열 | 단락 저항(≈0Ω)에 집중 발열 → 위치 특정 가능 |
| 안전 | 전류제한 설정 시 보드 추가 손상 방지 |

### 실전 절차

```
1. 멀티미터로 단락 레일 확인 (GND 대비 저항 측정)
2. 외부 PSU: 전압 1V, 전류제한 500mA~1A 설정
3. 단락 레일의 VCC 핀에 +, GND에 - 연결
4. 열화상 카메라 또는 손가락으로 발열 위치 탐지
5. 발열 부품 제거 후 재측정 → 반복
```

## 2. 구리 트랙 발열 분석

### 트랙 저항 공식

```
R = ρ · L / (W · T)

ρ = 1.72 × 10⁻⁸ Ω·m   (구리 비저항)
L = 트랙 길이 (m)
W = 트랙 폭 (m)
T = 구리 두께 (m)  — 표준 PCB: 35μm (1oz), 70μm (2oz)
```

**예시**: 35μm 두께, 0.2mm 폭, 10mm 길이 트랙
```
R = 1.72e-8 × 0.01 / (0.0002 × 0.000035) = 0.0245 Ω ≈ 24.5 mΩ
```

### 발열 계산

```
P = I² · R

1A 전류, 24.5mΩ 트랙:
P = 1² × 0.0245 = 0.0245 W  → 미지근

10A 전류 (단락):
P = 100 × 0.0245 = 2.45 W   → 과열·탄화
```

### 트랙 상태 판독

| 열화상 | 원인 | 확인 방법 |
|-------|------|---------|
| 트랙 전체 발열 | 과전류, 폭 너무 좁음 | 전류 측정 |
| 국소 발열 (한 점) | 트랙 크랙, 콜드 솔더 | 돋보기 + 재납땜 |
| 발열 없음 (전류 0) | 트랙 단선 | 멀티미터 연속성 |
| 부품 발열 | 내부 단락 | 1V 주입 후 열화상 |

## 3. PMIC 동작 원리

### PMIC 내부 구조

```
Battery / Adapter Input
         │
   ┌─────▼──────┐
   │  Switching │     I²C / SPI
   │  Regulator │◄────────────────── CPU
   │ (Buck/Boost│     전압·전류 명령
   └─────┬──────┘
         │  Power Sequencing
         │  (순서대로 Enable)
   ┌─────▼───────────────────────┐
   │  Rail 1:  1.0V  (CPU Core)  │
   │  Rail 2:  1.8V  (DDR, IO)   │
   │  Rail 3:  3.3V  (SPI, GPIO) │
   │  Rail 4:  5.0V  (USB, Fan)  │
   └─────────────────────────────┘
         │
   Feedback 저항 분배기
   → 출력 전압 정밀 제어
```

### Power Sequencing (전원 순서)

CPU 메인보드는 레일을 **순서대로** 켜야 함 — 순서 위반 시 부팅 실패 또는 손상:

```
3.3V (스탠바이) → 1.8V (메모리) → 1.05V (PCIe) → 1.0V (CPU Core)
     ↑ 먼저                                           ↑ 마지막
```

### PMIC 고장 진단표

| 증상 | 원인 추정 | 측정 방법 |
|------|---------|---------|
| 특정 레일 0V | Enable 핀 Low (시퀀서 미출력) | Enable 핀 전압 확인 |
| 레일 전압 낮음 | 피드백 저항 변경, 출력 캐패시터 불량 | FB 핀 전압 측정 |
| 레일 전압 높음 | 피드백 저항 단선 (분배비 변동) | FB 핀 저항 측정 |
| 과전류 차단 | 출력단 단락 → PMIC 보호 동작 | 1V 주입으로 단락 위치 탐색 |
| 간헐적 재시작 | 열폭주 (Thermal Shutdown) | 온도 모니터링 |

### Enable 핀 강제 인가 테스트

특정 레일이 안 켜질 때, 시퀀서 IC 불량인지 PMIC 불량인지 구분:

```
1. Enable 핀을 시퀀서 출력에서 분리
2. 3.3V (또는 데이터시트 기준 전압)를 Enable 핀에 직접 인가
3. 레일이 켜지면 → 시퀀서 IC 불량
4. 레일이 안 켜지면 → PMIC 자체 불량
```

## 4. 드론 하드웨어 연관성 (YFL 관점)

| 수리 원리 | 드론 보드 적용 |
|---------|-------------|
| 1V 주입 | FC(비행 컨트롤러) 전원 레일 단락 진단 |
| 트랙 발열 | ESC 고전류 경로 (모터 전원선) 과열 점검 |
| PMIC 진단 | Pixhawk PMIC 불량 시 (5V BEC, 3.3V 센서 레일) |
| Power Sequencing | FC 부팅 순서 불량 → IMU/GPS 초기화 실패 원인 |

### GT3 드론 전원 구조

```
배터리 (4S LiPo, 14.8V)
    │
    ├── ESC × 4 (모터 구동, 14.8V)
    │
    └── BEC (Battery Eliminator Circuit)
            │
            ├── 5V Rail  → FC, GPS, 수신기
            └── 3.3V Rail → IMU, 기압계, MCU IO
```
